# Gator - Blog Aggregator
 
## Requirements
 Gator is a blog aggregator that is built in Go and uses Postgres to store users, feeds, follows, and posts in a database. Both are required to run this program.
 
## Installation
Type in your CLI:
go install github.com/NamesNotRich/Gator

## Set Up
To set up your config file:
    In your home directory named `.gatorconfig.json`
